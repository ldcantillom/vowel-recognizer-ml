# vowel-recognizer-ml

Trabajo experimental de Machine Learning para la asignatura de **Inteligencia Artificial** de la **Universidad del Magdalena**.

## Tema

Reconocimiento óptico de caracteres (OCR) aplicado a vocales y dígitos numéricos, usando un conjunto de datos de imágenes manuscritas.

## Contenido

- `Respuestas taller.ipynb` — Cuaderno de Jupyter con las respuestas al taller formativo, incluyendo la inspección visual del dataset, conteo de imágenes por clase (A, E, I, O/U, 0) y una cuadrícula de imágenes de muestra.
- `Taller_formativo_inspección_datos.md` — Documento de inspección de datos.

## Notas

- El conjunto de datos completo (`CNN letter Dataset/`) no se incluye en este repositorio por su tamaño.
- Las imágenes de muestra (`aug*.jpg`) se incluyen únicamente con fines ilustrativos.
